Original algorithm source patches: NONE.

upstream/ contains exact Android android-13.0.0_r1 source bytes. The source lock
records each project URL, byte count and SHA-256. Builds fail on changed bytes.
runtime-sources.txt selects the classes compiled into the boot DEX. Additional
downloaded upstream classes are retained as reference, not falsely advertised as
executing framework code.

support/ contains compile-only declarations for Android/ART/JDK annotations,
hidden API contracts (Resources,
AssetManager, XmlBlock, StrictMode, XmlUtils, Arrays and LinkedHashMap.eldest). No support class is
packaged in framework.dex. They do not provide runtime algorithms or services.
Calls to these hidden signatures require the explicitly implemented Java core
backend; they never execute the declaration's placeholder method bodies.
No original source annotation or algorithm is deleted or rewritten.

android.jar supplies javac's Android API declarations and D8 verification types.
It is never an implementation input to the boot artifact. The only executable
inputs are the original sources listed in runtime-sources.txt and compiler-
generated nested/lambda classes derived from those sources.

SystemProperties retains its original Java implementation and native method
declarations. The browser binds only explicitly supported native method keys
from trusted boot definitions. The density proof uses native_get_int(String,int)
with read-only VM properties; it does not load Android ELF/JNI libraries.

The Android util/framework sources are Apache-2.0. java.util.Objects and
jdk.internal.util.Preconditions originate in OpenJDK via Android libcore and
retain GPLv2 with the Classpath Exception. Corresponding original source,
copyright headers and both license texts are included.

TypedArray is compiled unchanged with its seven-word attribute layout, Java
pooling, resize and getter algorithms. Its Resources/AssetManager inputs come
from the web platform's actual decoded ARSC/XML/string-pool state. Compile-only
contracts do not claim those Android services are implemented in this DEX.
Sparse collections, ContainerHelpers, GrowingArrayUtils, ArrayUtils, EmptyArray,
UtilConfig and VMRuntime are original source. ART allocation native methods map
to checked VM arrays; addressOf returns an opaque stable VM handle, never a web
or ELF pointer. The ART rule that only nonmovable primitive arrays have handles
is preserved. VMRuntime.getRuntime itself executes original Java singleton code.
ViewTreeObserver and its copy-on-write listener dispatch also run original Java.

The support compilation bootstraps original Pools.java once solely to type-check
Resources.mTypedArrayPool; it is then recompiled from the selected original source
into the implementation jar. No support declaration enters that implementation jar.

ActivityInfo, Parcelable, Parcelling, ArrayMap, ArraySet and MapCollections now
also come from complete unmodified original sources. ActivityInfo conversion
therefore executes its actual CONFIG_NATIVE_BITS loop and original cache setup.
Its inherited platform/service APIs (ComponentInfo, Parcel, compat policy) remain
compile-only contracts. Configuration.NATIVE_CONFIG_* values are regenerated
verbatim from the pinned full original Configuration.java; no Configuration
runtime/service algorithm is claimed. bootstrap/ supplies only the cyclic
ActivityInfo.Config annotation owner during metadata compilation; the original
ActivityInfo implementation replaces it in the runtime jar.

Graphics source compilation includes original Drawable, VectorDrawable, Rect,
RectF, Insets, Color, ColorStateList, StateSet, BlendMode/PorterDuff/Xfermode,
Property and PathParser algorithms. Native rendering, graphics handles, shaders,
image codecs, resource parsing and tracing remain explicit platform/VM boundaries.
A successfully compiled class is not a claim that every method or backend exists;
unavailable paths must report their exact unsupported API/native boundary.

Further complete original classes include WindowInsets and its bounds helpers,
ContentObserver, ViewConfiguration, AccessibilityNodeProvider, AutofillId,
ClipData/ClipDescription, Matrix and CursorAnchorInfo/SparseRectFArray/
EditorBoundsInfo. Their algorithms are not patched. Android Java metadata and
Java8 JDK API metadata are distinct compiler stages: original AbstractCollection,
AbstractList and AbstractSet compile against Android metadata, while selected
libcore ojluni collections (including ArrayList, HashMap/LinkedHashMap,
TreeMap/TreeSet/UUID/Modifier) compile with --release 8. Only classfiles generated
from selected source files enter D8; no JDK implementation class is copied.

Exact nested-source extractions (Paint/Path enums, View.AccessibilityDelegate,
AutofillCallback) and source measurement helper owner adaptations have independent
byte-range hashes in extracted/*/provenance.json. Their outer compilation shells
are excluded. Arrays is a partial original-source class: selected original
asList/backed-list/iterator, float hash and int binary-search algorithms retain
their canonical owner. One native copyOf overload declaration is compilation metadata
only; strip-arrays-compile-metadata.py removes its classfile method record
before D8. Neither a stub nor an invented implementation for that overload is
packaged. Other Arrays operations remain explicit runtime boundaries.

Complete original FrameLayout/LinearLayout/Gravity are compiled in the separate
opt-in profiles/layouts profile, preserving all source bodies. The profile is not
silently activated by the default framework build. Its support View/ViewGroup
classes provide metadata only; actual geometry, widget state and native rendering
remain platform inputs, with actual APK callbacks invoked during traversal.


OverScroller and Scroller (including spline physics and viscous-fluid
interpolation) are full original sources. AnimationUtils uses an exact extracted
subset of original clock state, ThreadLocal initializer and lock/unlock/current
methods; XML animation loading remains external. Source methods use the VM's
monotonic SystemClock boundary. Choreographer may lock/unlock this same original
clock during its frame callbacks. All stateful clock algorithms execute DEX.

Arrays now also includes all four original object/comparator sort entry points
and rangeCheck. Complete original TimSort and ComparableTimSort implement the
sorting algorithms; comparator calls dispatch to actual DEX callbacks. No JavaScript
sort substitutes the source path. The sole removed compilation-only method is
the copyOf overload declaration; array copying remains a checked VM primitive.


Observable and IdentityHashMap are complete original source classes. Reference,
ReferenceQueue, WeakReference, SoftReference and PhantomReference are complete
original libcore sources, including the original queue/list synchronization and
explicit enqueue algorithms. Only getReferent/refersTo0/clearReferent use exact
boot-only VM native bindings. The current VM retains objects until teardown; no
automatic GC, finalizer or Cleaner dispatch is invented. Explicit enqueue, poll
and remove of an already queued object execute original DEX. Blocking removal
on an empty queue fails specifically as unsupported-blocking. The Cleaner class
under support is compilation metadata only and is excluded from D8.

Trace.java is now the complete original Android13 source. The virtual device
reports nativeGetEnabledTags()=0 because it has no kernel atrace/profiling
session. Original Java isTagEnabled/beginSection/endSection/counter methods
therefore perform their actual short-circuit behavior. Emission and tracing
activation natives remain unbound; an explicitly enabled test mask reaches the
original validation or a specific unavailable-JNI error, never a fake emission.
