      Permissões
      sem app⌄
      
              
      Abra um APK para ver as permissões de execução (perigosas) que o app pede no manifesto.
      
              
      
              
      "Perguntar" é o padrão do Android: a permissão não é concedida e requestPermissions mostra o diálogo sobre o telefone. No Android, revogar uma permissão com o app aberto encerra o processo do app; aqui a revogação vale na hora e o app continua rodando (reabra o APK para vê-lo recomeçar sem a permissão).
      
              Localização simulada
              
      
                
                
                
                
              
      
              
      Com a permissão concedida e a localização ligada, LocationManager entrega esta posição (getLastKnownLocation e requestLocationUpdates). O cliente de localização do Google Play services não existe neste dispositivo virtual e continua falhando de forma explícita.
      
              
            
      
            
      
              
      Execução
      ⌄
      
              
              
      Este número é o orçamento do heap Java (objetos e arrays da VM; os demais orçamentos crescem junto). O navegador gasta mais que isso: tabelas do DEX, CanvasKit, rasters e um objeto JavaScript por objeto Java. Uma aba acima de ~2–4 GiB pode ser encerrada pelo navegador. O limite do motor é 2 097 152 objetos (4 GiB é limitado a ele).
      
              
      
              
              
      A VM roda o código do app muitas vezes mais devagar que um aparelho. Uma inicialização com centenas de threads pode passar dos 25 s padrão sem estar travada: o relatório "Instruction budget exceeded" mostra as threads ainda avançando. Um tempo maior deixa terminar; um laço infinito de verdade continua sendo encerrado com relatório, só que mais tarde.

              Redirecionar hosts
              0 ativas⌄
              
              
              Cada linha envia as requisições de um host para outro, como uma entrada de /etc/hosts que também pode trocar a porta e o esquema. O app continua vendo a URL original (e a lista de hosts permitidos vale para ela); só a requisição que o navegador faz vai para o destino. Origem: host, *.dominio ou host:porta. Destino: host, host:porta ou http://host:porta. Vale na hora e funciona junto com o Proxy.
