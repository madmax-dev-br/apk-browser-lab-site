        Execução
        ⌄
        
              
              
        
              
              
        Este número é o orçamento do heap Java (objetos e arrays da VM; os demais orçamentos crescem junto). O navegador gasta mais que isso: tabelas do DEX, CanvasKit, rasters e um objeto JavaScript por objeto Java. Uma aba acima de ~2–4 GiB pode ser encerrada pelo navegador. O limite do motor é 2 097 152 objetos (4 GiB é limitado a ele).
        
              
        
              
        
                Memória do núcleo Wasm reabra o APK para aplicar
                
        
                  
                  
                  
                
        
                
        
                
        
                
        Só vale com o motor "Núcleo WebAssembly" (o padrão), quando o APK é aberto de novo. Heap: objetos e arrays do app. Metaspace: classes e métodos ligados (cresce com o tamanho do app). Threads: quantas threads Java podem estar vivas ao mesmo tempo. Os três dividem uma memória de no máximo 2048 MiB; o resumo do diagnóstico mostra quanto de cada um está em uso.
        
                
              
        
              
              
        A VM roda o código do app muitas vezes mais devagar que um aparelho. Uma inicialização com centenas de threads pode passar dos 25 s padrão sem estar travada: o relatório "Instruction budget exceeded" mostra as threads ainda avançando. Um tempo maior deixa terminar; um laço infinito de verdade continua sendo encerrado com relatório, só que mais tarde.

                Redirecionar hosts
                0 ativas⌄
                
              
                Cada regra envia as requisições do app para um host a outro destino, como uma entrada de /etc/hosts que também pode trocar a porta e o esquema. O app continua vendo a URL original; só a requisição que o navegador faz vai para o destino, e ela não precisa estar em “Hosts permitidos” (o modo offline continua valendo). Origem: https://api.exemplo.com, api.exemplo.com, host:porta ou *.dominio. Destino: host, host:porta ou http(s)://host:porta; sem esquema, localhost e 127.0.0.1 usam http. Um servidor local precisa responder CORS para a página do lab (ou use o relay CORS com --allow-private). Vale na hora, conta as respostas de cada regra e marca as requisições no painel Rede.

                  Mock de endpoints
                  0 ativos⌄
                  
              
                  Ferramenta de depuração: uma requisição do app que casa com um mock da lista é respondida pelo lab com a resposta configurada e não vai à rede. O primeiro mock ativo que casar, na ordem da lista, responde, antes da lista de hosts permitidos, do modo offline, de Redirecionar hosts e do Proxy. Vale para HttpURLConnection, OkHttp e outros clientes sobre java.net.Socket e DownloadManager; páginas de WebView são carregadas pelo navegador e não passam pelos mocks. Cada resposta é contada, marcada no painel Rede (e no HAR), citada no Resumo, e a primeira de cada mock gera um aviso no Logcat.
