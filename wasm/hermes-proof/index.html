Hermes HBC96 → WebAssembly

VM C++ oficial Hermes 0.13.0 compilada para Wasm. O programa público testa arrays, closures e exceções, em um Worker do navegador.

Este experimento não executa um APK Android completo. Nenhum módulo nativo React Native, JNI, sistema de arquivos do computador ou acesso de rede do programa é fornecido. A porta Unicode desta versão upstream é parcial.
